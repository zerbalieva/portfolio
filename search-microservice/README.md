# Search Microservice

## О проекте

Микросервис для поиска музыкальных сущностей: артисты, треки, альбомы, плейлисты, подкасты и аудиокниги.

## OpenAPI спецификация

В проекте разработана OpenAPI 3.0.4 спецификация, которая описывает REST API микросервиса.

### Доступные методы

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/search` | Поиск музыкальных сущностей по запросу |
| POST | `/create_playlist` | Создание нового плейлиста |
| POST | `/add_track_to_playlist` | Добавление трека в плейлист |

### Структура ответа

Поиск возвращает результаты, сгруппированные по категориям:

- `artists` — исполнители
- `tracks` — треки
- `albums` — альбомы
- `playlists` — плейлисты
- `podcasts` — подкасты
- `audiobooks` — аудиокниги

### Коды ответов

| Код | Описание |
|-----|----------|
| 200 | Успешный поиск |
| 400 | Неверный запрос (отсутствует query) |
| 404 | Ресурс не найден |
| 500 | Ошибка сервера или БД |

## Использованные технологии

`OpenAPI 3.0.4` · `YAML` · `REST API` · `JSON`
